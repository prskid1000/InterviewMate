# Job Description — Senior Java Backend Developer

We are looking for a Java Backend Developer to design, build, and scale our
core platform services.

**Responsibilities**
- Design and develop RESTful microservices in Java / Spring Boot
- Own services end-to-end: design, coding, testing, deployment, monitoring
- Optimize relational database access (MySQL/PostgreSQL) for high traffic
- Collaborate with frontend and mobile teams on API contracts
- Participate in code reviews and system design discussions

**Requirements**
- 4+ years of Java backend experience (Java 11+, Spring Boot)
- Strong grasp of OOP, design patterns, collections, concurrency, JVM basics
- Hands-on experience with SQL databases, caching (Redis), and message queues
- Experience with unit/integration testing and CI/CD pipelines
- Familiarity with Docker and cloud deployment (AWS preferred)
- Good understanding of system design: scalability, availability, consistency
